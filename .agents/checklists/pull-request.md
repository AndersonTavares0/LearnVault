# Pull request checklist

- [ ] Agent instructions and the relevant repository policies were read before changes.
- [ ] Branch is focused and based on current `main`.
- [ ] The PR template has factual summary, governance impact, validation, and safety entries.
- [ ] Required tests and affected configuration checks have run.
- [ ] No course files, secrets, generated output, or personal data are included.
- [ ] Documentation, migrations, and deployment notes are updated when applicable.
- [ ] Security, persistence, and release/update changes have independent review evidence
      for the proposed SHA under `.agents/policies/agent-collaboration.md`; later changes
      that invalidate conclusions have been reviewed again.
- [ ] Required review, checks, and conversations are complete before merge. CODEOWNERS
      remains informative ownership metadata, not a mandatory approval gate.
