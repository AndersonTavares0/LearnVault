# Pull request checklist

- [ ] Branch is focused and based on current `main`.
- [ ] The PR template has factual summary, governance impact, validation, and safety entries.
- [ ] Required tests and affected configuration checks have run.
- [ ] No course files, secrets, generated output, or personal data are included.
- [ ] Documentation, migrations, and deployment notes are updated when applicable.
- [ ] Required review, CODEOWNER review, checks, and conversations are complete before merge.
