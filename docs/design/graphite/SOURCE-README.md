# LearnVault — HTML aprovado separado por prancha

Estes 15 HTMLs são extrações do arquivo original, preservando o CSS integral, os elementos e o conteúdo de cada seção. Não são novas propostas de design.

## Como usar

1. Abra `00-referencia-original-completa.html` para ver a proposta inteira.
2. Abra cada `NN-*.html` diretamente no navegador para examinar a tela isolada.
3. Use o HTML/CSS da tela correspondente como base concreta para a implementação Svelte, preservando a aparência.
4. Substitua apenas o conteúdo fictício por dados reais ou fixtures isoladas de teste.
5. As pranchas de decisões documentam regras de UX e não são necessariamente rotas a criar.
6. Não trate os controles estáticos do mockup como funcionalidades prontas. Integre-os ao estado real ou documente a necessidade de implementação.

## Critério visual

Compare a aplicação e cada HTML em mesma resolução e tema. A referência principal é Graphite claro; valide também o tema escuro com a mesma hierarquia. Preserve as regras de autenticação, mídia, rescan, catálogo e isolamento de usuários.
