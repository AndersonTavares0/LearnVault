## Origem, dimensões e estilo

- HTMLs originais: `docs/design/graphite/NN-*.html`; o conjunto completo está em `00-referencia-original-completa.html`. Cada prancha contém o CSS original inline.
- Viewport de comparação: 1440×1000; board `max-width:1500px; padding:24px`; `wrap` até 1280 px. Breakpoints originais em 950/700 px; algumas pranchas usam 800/850/520 px para seus componentes específicos.
- Tokens originais: fundo `#f2f5f7`/`#f7f9fa`, branco, tinta `#1b2832`, secundário `#64737e`, linha `#d9e1e6`, teal `#276f73`, petróleo `#14232b`/`#20343d`, âmbar `#a65d20`; radius geral 10 px. Tipografia `Inter, ui-sans-serif, system-ui, "Segoe UI", sans-serif`, corpo 14 px/1.45.
- CSS original integral extraído para `apps/web/src/graphite/reference.css`; `base.css` preserva tokens/regras comuns. `shell.css` contém integração específica do produto, não substitui a referência.
- Para cada prancha, a coluna acima cita os seletores CSS originais e a implementação Svelte; diferenças de dados demonstrativos estão separadas das fontes reais.

## Proveniência e limites

- Original aprovado: esta pasta, HTMLs originais e CSS inline; o pacote fornecido tem 15 pranchas e a prancha navegável consolidada.
- Tentativa anterior: código da branch `feat/phase7-graphite-redesign`, screenshots e matriz do PR #274. Evidências/mapeamento, não origem visual. Não usar seus componentes como atalho.
- #274 continua aberto e intocado. PR #272 foi confirmado pelo mantenedor como referência de comportamento e dados funcionais; a implementação de notas e decisões funcionais são aproveitáveis, mas o CSS/componentes visuais da tentativa não são fonte do redesign.
- Dados de demonstração não são dados reais. Métricas sem fonte de backend ficam ausentes ou indisponíveis. Capturas usam fixtures temporárias, nunca bibliotecas reais.

Branch `feat/graphite-redesign-original-boards`, criada isoladamente a partir de `origin/main` no commit `278e228`. A tabela por prancha acima é o contrato de fonte HTML/CSS, componentes, layout, comportamento e limites de dados.
