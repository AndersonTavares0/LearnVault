A patch release: the Flatpak desktop app starts on NVIDIA Wayland systems and reports its real version, plus security and robustness fixes for the server. Your original files are never moved, renamed or changed.

- **Flatpak:** the app no longer crashes on NVIDIA with Wayland (WebKitGTK DMABUF rendering is disabled inside the sandbox), and Settings shows the real installed version instead of 0.0.0. Source builds of the server now report `dev` instead of `0.0.0`.
- **Security hardening:** remote WebDAV and SMB source hostnames are resolved once and checked against the address policy before connecting, and WebDAV ignores `HTTP_PROXY`/`HTTPS_PROXY`; cover discovery and scan hashing open files through the same confined opener as playback; offline sync no longer returns notes or study events for courses whose access was revoked; and the login throttle can no longer lock out new users when the table fills.
- **Reverse proxies:** login rate limiting reads `X-Forwarded-For` only, from trusted proxies. Proxies that send only `X-Real-IP` now share one bucket; see the reverse proxy section in the distribution guide.
- **Health check:** `/healthz` readiness no longer depends on the database writer being free.
- **Fixes:** signing in with a temporary password now takes you to your account page to choose new credentials before the library, a library configured with an empty root no longer breaks course seeding, and lesson search no longer drops results.
- **Maintenance:** published-release verification checks each architecture image digest, and the rollback, Flatpak and security docs were corrected.
