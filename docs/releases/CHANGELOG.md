## [0.9.5](https://github.com/AndersonTavares0/LearnVault/compare/v0.9.4...v0.9.5) (2026-11-19)

A maintenance release: security hardening, recovery when course files go missing, accessibility and mobile fixes, an About section and English deploy files. Your original files are never moved, renamed or changed.

### Highlights

- **Windows desktop users still on v0.8.0: install this release manually once.** The updater public key changed after v0.8.0, so the in-app updater cannot verify payloads. Later updates work normally.
- **Security hardening:** cover extraction from a video reads only that file, so a crafted file cannot pull frames from elsewhere on the disk; PDF annotation endpoints enforce course access; credential changes are rate-limited per user and source; and only administrators can force an update check.
- **Course recovery:** a course whose folder is removed or renamed is marked missing instead of failing the scan, and its lesson page keeps completion state, notes, timestamps and cards reachable. Playback and resume stay hidden while the file is gone, and restoring the folder marks the media available again with progress intact.
- **Accessibility:** after navigation, keyboard focus moves to the new page heading, and the progress heatmap can be scrolled with the keyboard. Muted text stays above 4.5:1 contrast on the rose and solarized surfaces, and the weekly streak text is easier to read.
- **Mobile and layout:** focused controls stay above the bottom navigation bar, lesson tool tabs wrap instead of scrolling, and Settings and the top bar fit a 320 px phone. The top bar stays in place while the content below it scrolls.
- **Small fixes:** audio lessons are labelled by media kind instead of video, review deck counts use singular and plural forms, tab titles follow navigation, and an expired session returns to sign-in instead of repeating errors.
- **Brand and About:** the default accent uses the brand ink, with the brand gold as its dark theme colour and reward colour; other presets are unchanged. Settings has an About section with the installed version, the round seal, *Sapere aude*, the read-only statement and a link to the repository.
- **Deploy files:** the remaining Portuguese text in the deployment files is now English, with Brazilian Portuguese kept as localized entries.
- **Database:** no schema migrations in this release.

## [0.9.2](https://github.com/AndersonTavares0/LearnVault/compare/v0.9.1...v0.9.2) (2026-11-16)

A maintenance release for the course folders you already own: smarter library detection, covers taken from your own videos, and fixes for large network libraries. Your original files are never moved, renamed or changed.

### Highlights

- **Nested libraries:** folders arranged as Area / Subcategory / Course now register each course on its own, instead of merging unrelated courses under one category folder. Hidden and system folders (`.Trash`, `@eaDir`, `$RECYCLE.BIN`, `System Volume Information`) are skipped.
- **Covers:** a course with no local cover image gets a frame taken from its first video (this needs FFmpeg). Covers are also detected during background indexing, not only on a manual rescan.
- **Course structure:** handouts, PDFs and notes inside a module that has lessons are no longer flagged as loose materials.
- **Large libraries:** a catalog rescan no longer holds the database lock while it walks every course, so the health check and sign-in keep working during a scan of a large network (NFS) library.
- **Time zone:** the container image includes `tzdata` and Compose exposes `TZ` (default `UTC`), so named zones such as `America/Sao_Paulo` count your study days correctly instead of silently falling back to UTC.
- **Interface:** long course titles no longer run under the favorite and manage buttons. The habit tiles, the Progress summary and the course hero were polished, and the hero shows a blurred cover backdrop when artwork exists. The video control bar keeps its transparent gradient.

## [0.9.1](https://github.com/AndersonTavares0/LearnVault/compare/v0.8.0...v0.9.1) (2026-11-15)

A redesigned study space for course folders you already own, with PDF reading, remote course sources and offline sync. Your original files are never moved, renamed or changed. There is no `v0.9.0` release: the `0.9.0` candidates were superseded by this one.

### Highlights

- **Redesigned screens:** sign-in is a centered single form; the library offers Grid, List, Compact and Shelf views with poster cards; the course page and the lesson sidebar were reworked for clearer hierarchy.
- **Lesson workspace:** cinema mode uses a black stage, the curriculum shows done, current and not-started modules, and a "Find a lesson" field filters the course content. Rarely used player controls moved into a settings menu.
- **Notes** are a notebook grouped by course and lesson, with timestamps. **Progress** leads with three labelled metrics, and the study-day heatmap covers the last year.
- **PDF lessons** open in the app: continuous reading, search with Ctrl+F, table of contents and thumbnails, highlights, underlines and notes. Marks are stored in the database, never in the file; a copy of the PDF can be saved with its marks, and a mark can be sent to the lesson notes.
- **Remote course sources:** read-only WebDAV and SMB libraries, with a folder browser to choose which folders become courses.
- **Sync:** offline desktop changes sync with the server, including flashcards and the deletion of notes and bookmarks.
- **Search and study:** global full-text search over notes and the catalog, favorites for courses and lessons, flashcards linked to lesson moments, and local student accounts with per-course access.
- **Resume** strip on the home page, and course cards show accurate lesson counts.
- **Linux desktop:** a Flatpak bundle (`.flatpak`) for amd64 and arm64. Inside Flatpak the in-app updater and the system video player are disabled; install it with `flatpak install --user --bundle`.
- **Container image:** amd64 and arm64 are built on native runners, signed with keyless cosign and scanned for HIGH and CRITICAL vulnerabilities before any tag is applied. Compose now uses the published image by default, and the Podman Quadlet unit updates automatically.
- **Security:** course and media access boundaries are enforced, login rate limiting uses the forwarded client address, sessions are renewed and pruned, remote source URLs refuse link-local targets, and SQLite is bundled at 3.54 (CVE-2026-119375).

## [0.1.0] - 2026-10-14

The project governance and documentation baseline.

### Added

- Initial project governance and contribution documentation.
- Policies, playbooks, checklists and an ADR template in `.agents/`.
- Canonical documentation layout and a controlled wiki sync flow.

### Changed

- Standardized the repository on Go 1.26, Node.js 24, pnpm 11.28.5 and the frozen pnpm lockfile.
- Updated `golang.org/x/crypto` to v0.58.0 and `modernc.org/sqlite` to v1.60.1, together with the Go 1.26 toolchain.
- Kept generated SPA output, runtime data, caches, secrets and local tools out of Git.

### Security

- The external course library stays read-only and outside version control, tests and backups.
