# Screenshots Graphite

Capturas sintéticas da interface do LearnVault após o redesign Graphite. Nenhuma
imagem contém cursos reais, credenciais ou dados pessoais.

| Captura | Viewport | Tema |
| --- | --- | --- |
| `reference-login-light.png` | 1440×1000 | Claro, split login Graphite |
| `reference-login-mobile-dark.png` | 390×844 | Escuro, split login mobile |

As imagens documentam o fluxo de autenticação e a adaptação responsiva da proposta
visual aprovada; os demais estados usam os mesmos tokens e componentes preservados
no shell da SPA. Os arquivos `graphite-login-*.png` são capturas da primeira iteração
e não representam mais a composição final.
