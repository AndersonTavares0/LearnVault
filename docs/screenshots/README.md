# Screenshots Graphite

Capturas sintéticas da interface do LearnVault após o redesign Graphite. Nenhuma
imagem contém cursos reais, credenciais ou dados pessoais. O catálogo aparece vazio
porque não há biblioteca real conectada ao ambiente de captura.

| Captura | Viewport | Tema |
| --- | --- | --- |
| `reference-home-light.png` | 1440×1000 | Claro, área autenticada vazia |
| `reference-home-dark.png` | 1440×1000 | Escuro, área autenticada vazia |
| `reference-home-mobile-dark.png` | 390×844 | Escuro, mobile |
| `reference-login-light.png` | 1440×1000 | Claro, split login |
| `reference-login-mobile-dark.png` | 390×844 | Escuro, split login mobile |

As imagens documentam o shell aprovado do Graphite: barra petroleum com navegação
horizontal, busca real, chip compacto de Pomodoro, cabeçalho da biblioteca, faixa de
métricas e estados vazios. Os demais estados reutilizam os mesmos tokens e
componentes. Os arquivos `graphite-login-*.png` são capturas da primeira iteração e
não representam a composição final.
